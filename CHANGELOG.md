# KUK360 CHANGELOG

## KUK360 3.0.0 (2026-11-01)

- Ported from C# / WPF to C++17 / Qt 6 / OpenGL
- License changed from MIT to GPL-3.0-only
- Runs on Windows, macOS and Linux
- 360° projection rendered on the GPU with the algorithm ported from Pannellum
- Look around with W / A / S / D and zoom with E / Q in 360° projection
- Added alignment grid in 360° projection
- Added support for WebP images
- Supports zooming with pinch gestures on touch screens and trackpads
- Follows the light or dark mode of the system

## KUK360 2.1.0 (2024-02-24)

- Added ability to automatically rotate in 360° projection
- #7 - Added ability to display grid in flat projection
- #6 - Added "Check for updates" feature
- #3 - Possibly fixed huge icons in the main menu
